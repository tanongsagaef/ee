เทรนด์ (Trend)
เทียบราคาปัจจุบันเทียบกับเส้นค่าเฉลี่ย SMA20 และ SMA50 เพื่อดูทิศทางของหุ้นในระยะสั้น-กลาง
ขาขึ้น: ราคา > SMA20 > SMA50 (เรียงจากมาก) = แนวโน้มขาขึ้นชัดเจน ไม่มีดัยยังหุ้น
ขาลง: ราคา < SMA20 < SMA50 (เรียงจากน้อย) = แนวโน้มขาลงชัดเจน ยังไม่ควรเข้าซื้อ
ข้อควรระวัง: เป็น lagging indicator คำนวณจากราคาย้อนหลัง ไม่ได้บอกอนาคต และไม่บอกว่าเทรนด์จะกลับตัวเมื่อไหร่
RSI (14) — ดัชนีความแรงสัมพันธ์
วัดความเร็ว/ขนาดของการขึ้นลงราคาในช่วง 14 วัน มีค่า 0-100
RSI > 70: ซื้อมากเกินไป (overbought) — ราคาอาจวิ่งเร็วเกินไป เสี่ยงพักตัว/ย่อตัว
RSI < 30: ขายมากเกินไป (oversold) — อาจเป็นจุดหวะสะสมของ ใช้เอาระวัง เพื่ออาจกลับตัว
ใช้สูตร Wilder's smoothing มาตรฐาน คำนวณต่อเนื่องจากข้อมูลย้อนหลังทั้งชุด (~100 วัน) — ค่าจะใกล้เคียงกับ TradingView
Relative Strength vs SPY (3 เดือน)
เทียบผลตอบแทน 3 เดือนของหุ้นตัวนี้กับ SPY (ตัวแทนตลาดรวม)
บวก (+): หุ้นตัวนี้ทำผลงานดีกว่าตลาดโดยรวม แสดงถึงแรงซื้อที่แข็งกว่าเฉพาะตัว
ลบ (-): หุ้นตัวนี้แพ้ตลาด อาจมีปัจจัยลบเฉพาะตัวที่ฉุดราคา
ความผันผวน (Annualized Volatility)
คำนวณส่วนเบี่ยงเบนมาตรฐานของผลตอบแทนรายวันย้อนหลัง 30 วัน แล้วปรับเป็นรายปี
ต่ำ (< 20%): ราคานิ่ง ความเสี่ยงต่ำ เหมาะสำหรับสายระมัดระวัง
สูง (> 45%): ราคาแกว่งแรง กำไร/ขาดทุนเร็ว ต้องบริหารขนาดสถานะให้เล็กลง
ห่างจากจุดสูงสุด / ขึ้นมาจากจุดต่ำสุด
Drawdown จากจุดสูงสุดในกรอบข้อมูล (~100 วัน เพราะ 52 สัปดาห์เต็มไม่มีเพราะเก็บข้อมูลแบบ compact) และระยะที่วิ่งขึ้นมาแล้วจากจุดต่ำสุดในกรอบ 6 เดือน
ห่างจากจุดสูงน้อย = ราคาใกล้จุดสูงสุด เทรนด์แข็งแรง ยังไม่เสี่ยงจุดกลับตัว
ขึ้นมาแล้วจากจุดต่ำ (> 80%) = วิ่งมาแล้วมาก อาจเหนื่อย ระวังพักตัว/แรงขายทำกำไร
Volume วันล่าสุด เทียบค่าเฉลี่ย 50 วัน
ปริมาณการซื้อขายวันล่าสุดหารด้วยค่าเฉลี่ย 50 วัน (แสดงเป็นเท่า)
> 1.4x: วอลุ่มพุ่งกว่าปกติ อาจมีเงินก้อน/รายใหญ่เข้าเก็บ (เชิงสัญญาณ) เท่านั้น เป็นสัญญาณยืนยันการเคลื่อนไหวของราคา
ต่ำกว่านั้น: ไม่มีสัญญาณชัดเจน ราคานั้นอาจอ่อนแรงเป็น noise รายวัน
ระดับความเสี่ยง (Risk Level)
สรุปความผันผวนรวมกับ drawdown เป็น ต่ำ/ปานกลาง/สูง
เป็นระดับการปรับขนาดสถานะเท่านั้น ใช้ Position Size ไม่ได้กำหนดว่าซื้อ-ขาย
P/E Ratio
ราคาต่อกำไรต่อหุ้น สะท้อนว่าตลาดยอมจ่ายเท่าไหร่ต่อกำไรบริษัท
P/E ต่ำ (< 15): มูลค่าถูกเมื่อเทียบกำไร เหมาะสำหรับสายเน้นคุณค่า/มีพื้นฐาน
P/E สูง (> 40) หรือติดลบ: ตลาดคาดหวังการเติบโตสูงมาก หรือบริษัทยังขาดทุนอยู่ ความเสี่ยงด้าน valuation สูง
SMA20/SMA50, EMA12/EMA26, MACD, ATR
SMA/EMA = เส้นค่าเฉลี่ยเคลื่อนที่ ใช้ยืนยันทิศทางเทรนด์และจุดตัด (crossover) — EMA คำนวณแบบ warm-up เต็มช่วง (seed ด้วย SMA แล้วไล่ทั้งชุดข้อมูล)
MACD (12/26/9): ค่าที่แสดงคือ histogram = MACD − Signal. บวก = โมเมนตัมขาขึ้น, ลบ = ขาลง, ตัดผ่าน 0 = สัญญาณเปลี่ยนโมเมนตัม
ATR (14): ช่วงราคาที่หุ้นแกว่งเฉลี่ยต่อวัน (Wilder) ใช้กะระยะ Stop Loss — ทั่วไปตั้งที่ 1.5–2 เท่าของ ATR จากจุดเข้า
ตำแหน่งในกรอบ 52 สัปดาห์: 0% = ราคาต่ำสุดของปี, 100% = สูงสุดของปี
คะแนนรวม (Score 0-100)
คำนวณจากด้าน BULLISH/BEARISH ที่ดูแค่เทรนด์+RS — คะแนนที่รวม 7 ปัจจัย (เทรนด์, ขนาดของ RS, RSI, Volume, ความผันผวน, ระยะยืนตัว, P/E) โดยให้น้ำหนักตาม "ขนาด" ของสัญญาณด้วย ไม่ใช่แค่บวก/ลบ เช่น RS +0.2% กับ +15% จะได้คะแนนไม่เท่ากัน
70-100: ปัจจัยส่วนใหญ่เอียงข้างบวกพร้อมกัน
45-69: ปัจจัยผสมกัน ควรดูภาพรวมประกอบ ยังไม่หนักเอียงไปทางใดทางหนึ่ง
0-44: ปัจจัยส่วนใหญ่เอียงลบ
คะแนนนี้ "รายละเอียดคะแนน" เปิดผลลัพธ์เพื่อดูว่าแต่ละปัจจัยให้คะแนนเท่าไหร่ — เป็นคะแนนแบบ rule-based ถ่วงน้ำหนักเอง ไม่ใช้โมเดลสถิติหรือ machine learning
Verdict (BULLISH / BEARISH / NEUTRAL)
รวมคะแนนจากเทรนด์ + relative strength เท่านั้น (metric อื่นเป็นข้อมูลประกอบให้อ่านต่อเท่านั้น ไม่ได้ถูกคำนวณเข้าไปที่คะแนนนี้ — แต่ถูกคำนวณเข้าคะแนนรวม 0-100 ด้านบนแล้ว)
เป็นการสรุปเชิงกฎ ไม่ควรใช้เป็นสัญญาณซื้อ-ขายเดี่ยวๆ ควรอ่านประกอบกับคะแนนรวมและ Devil's Advocate ก่อนเสมอ
แนวทางราคาเข้า (เข้าตอนนี้ / รอย่อ / ยังไม่ควรเข้า)
แนะนำอัตโนมัติ ที่คำนวณจาก SMA20/SMA50, RSI และระยะยืนตัวที่มีอยู่แล้วด้านบน ไม่ใช่ข้อมูลใหม่จากราคา — เป็นหลักเกณฑ์ว่าเทรนด์ขาขึ้นมั่นย่อลงมาใกล้ SMA20 ต่ออีกต่อ และราคาที่ยืนเหนือ/RSI สูงเกินไปมีความเสี่ยงเลื่อนราคาสูงกว่าปกติ
"อยู่ในโซนที่ควรพิจารณาเข้าซื้อ" = เทรนด์ขาขึ้น + ยังไม่ยืนตัวมาก
"รอย่อก่อน" = เทรนด์ดีแต่ RSI overbought หรือราคาขึ้นมาเยอะจากจุดต่ำสุดแล้ว
"ยังไม่ควรเข้า" = เทรนด์ยังอยู่ในทิศทางขาลง
โซนราคาที่ขึ้นเป็นเพียงแนวทางเชิงเทคนิคเท่านั้น ไม่ใช่ราคาที่รับประกันว่าจะเข้าได้หรือไม่หลุด ควรใช้ร่วมกับ Position Sizing และ Devil's Advocate เสมอ
รายละเอียดคะแนน — กดเพื่อดู กดเพื่อปิด

ปัจจัยเชิงคุณภาพเพิ่มเติม (Finnhub)

ข้อมูลจาก Finnhub — เป็นประกอบการวิเคราะห์เท่านั้น ไม่ได้ถูกคำนวณรวมเข้าคะแนน verdict ด้านบน

ข่าวล่าสุด (Finnhub)

    แสดงเฉพาะหัวข้อข่าว — กดเพื่ออ่านเนื้อหาเต็มจากต้นทาง เพื่อหาข่าวไม่ได้ถูกคำมาสรุปหรือให้คะแนนอัตโนมัติ

    การซื้อขายของผู้บริหาร (Insider Transactions — Finnhub)

      P = ซื้อในตลาดเปิดด้วยเงินส่วนตัว, S = ขาย — เป็นประกอบการวิเคราะห์เท่านั้น ไม่ได้ถูกคำนวณรวมเข้าคะแนน

      มุมมองนักวิเคราะห์ Wall Street (Finnhub)

      สรุปจำนวนนักวิเคราะห์ที่ให้เรตติ้งล่าสุด — ไม่ได้ถูกคำนวณรวมเข้าคะแนน

      เหตุผลค้าน (Devil's Advocate) — ก่อนตัดสินใจ

      ข้อมูลนี้เป็นเครื่องมือช่วยวิเคราะห์จากข้อมูลราคาย้อนหลังและปัจจัยเชิงปริมาณเท่านั้น ไม่ใช่คำแนะนำการลงทุน และไม่มีสัญญาณรับประกันผลลัพธ์ของการซื้อขายทุกกรณี

      Watchlist

      คำนวณขนาดสถานะ (Position Sizing)

      บันทึกการตัดสินใจ

      Bulk Scan — วิเคราะห์หลายหุ้นพร้อมกันทีเดียว

      ดึงหุ้นทั้งตลาด NASDAQ (~4,000 กว่าตัว) พร้อมกันไม่ได้จริง เพราะ Twelve Data free key จำกัด 8 request/นาที และ ~800 request/วัน — แนะนำที่ดึงให้วางรายชื่อหุ้นเอง เช่น "ดัชนี" (เช่นเดิมใส่ 60 ตัว/รอบ) แล้วเลือกวิเคราะห์ให้อัตโนมัติเฉพาะไม่เกินโควตา โดยจะข้ามข้อมูล P/E (Statistics) เพื่อประหยัด request — ถ้าอยากได้ P/E เต็ม ให้กดวิเคราะห์เดี่ยวเพื่อวิเคราะห์แบบมีรูปแบบเต็ม [1]

      ผลลัพธ์ (คลิกหัวตารางเพื่อเรียง · คลิกแถวเพื่อดูวิเคราะห์เต็ม)

      ยังไม่มีผลลัพธ์ — วางรายชื่อหุ้นแล้วกดเริ่ม Bulk Scan

      เทียบทีม — คะแนน + ผลตอบแทนย้อนหลัง

      ใส่รายชื่อหุ้นทีม A และทีม B (แนะนำทีมละไม่เกิน 10 ตัว) เพื่อจะวิเคราะห์ทุกตัวแล้วสรุปคะแนนเฉลี่ยและผลตอบแทนย้อนหลัง 1 เดือน / 3 เดือนของแต่ละทีมมาเทียบกัน — ทีมชนะคือทีมที่ได้คะแนนเฉลี่ยรวมสูงกว่าเท่านั้น ไม่ใช่การรับประกันว่าทีมที่ชนะจะทำผลตอบแทนย้อนหลังดีกว่าจะชนะอนาคตด้วย
